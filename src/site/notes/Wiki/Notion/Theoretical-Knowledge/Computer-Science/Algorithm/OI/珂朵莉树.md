# 珂朵莉树（ODT）

日期：2026-06-13

## 解决什么问题

珂朵莉树，又叫 ODT，本质是“颜色段均摊”技巧。它维护一组按左端点排序、互不相交的区间，每个区间代表一段相同的值。

它适合带有区间覆盖/区间赋值的问题。只要经常把一段区间推平成同一个值，区间数量就会被压缩，遍历这些颜色段会比较方便。

## 核心思想

先把数组压缩成若干段：

```text
[1, 3] = 5, [4, 8] = 2, [9, 10] = 7
```

当要操作 `[l, r]` 时：

1. `split(r + 1)`：让 `r + 1` 成为新区间的左端点。
2. `split(l)`：让 `l` 成为新区间的左端点。
3. 此时 `[l, r]` 内的节点都完整落在操作范围里。
4. 查询就遍历这些节点；覆盖就删除它们并插入一个新区间。

## 例子

假设原数组是：

```text
位置：1 2 3 4 5 6 7 8
值：  1 1 1 2 2 2 3 3
```

初始颜色段：

```text
[1, 3] = 1
[4, 6] = 2
[7, 8] = 3
```

执行 `assign(3, 7, 9)`：

1. `split(8)`：把 `[7, 8] = 3` 切成 `[7, 7] = 3` 和 `[8, 8] = 3`。
2. `split(3)`：把 `[1, 3] = 1` 切成 `[1, 2] = 1` 和 `[3, 3] = 1`。
3. 删除 `[3, 3] = 1`、`[4, 6] = 2`、`[7, 7] = 3`。
4. 插入 `[3, 7] = 9`。

最终颜色段：

```text
[1, 2] = 1
[3, 7] = 9
[8, 8] = 3
```

最终数组：

```text
1 1 9 9 9 9 9 3
```

## 关键操作

- `split(x)`：找到包含 `x` 的区间，把它拆成左半段和右半段，返回右半段。
- `assign(l, r, v)`：切出 `[l, r]`，删除旧区间，插入 `[l, r] = v`。
- `perform(l, r)`：切出 `[l, r]`，遍历其中的完整区间做统计。

在 `std::set` 实现里，通常先 `split(r + 1)` 再 `split(l)`，这样可以避开迭代器失效带来的坑。

## 复杂度和适用条件

`split` 用平衡树维护时通常是 `O(log s)`，其中 `s` 是当前区间数量。真正的成本来自 `perform` 遍历了多少个颜色段。

珂朵莉树的关键前提是：操作中有足够多的区间覆盖，能不断减少碎段。OI Wiki 提醒，如果只做查询/遍历而不覆盖，或者数据被刻意构造，区间数可能越来越多，复杂度会退化得很厉害。

结论：它适合随机数据、区间赋值很多、题目不容易卡构造的场景；不适合作为线段树的通用替代品。

## 易错点

- 区间是闭区间还是左闭右开要统一。
- 必须完整初始化维护范围，常见写法会放一个哨兵边界。
- `r = n` 时，`split(r + 1)` 要保证边界存在或被合法处理。
- 相邻同值区间最好合并，避免碎段膨胀。
- 不要忽略 ODT 的随机/均摊条件。
